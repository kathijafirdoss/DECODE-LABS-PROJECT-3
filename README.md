# DecodeLabs Project 3 - AI Recommendation Logic

## 📌 Project Overview

This project is part of the **DecodeLabs Artificial Intelligence Industrial Training**.

The objective is to create a simple recommendation system based on user preferences.

The system takes user interests as input, matches them with item attributes using similarity logic, and displays recommended items.

## 🎯 Project Goal

- Take user input such as choices or interests
- Match user preferences using logic or similarity
- Display recommended items

## 🤖 Recommendation Approach

This project uses:

- TF-IDF Vectorization
- Cosine Similarity
- User Preference Matching

The similarity score is used to rank items and provide relevant recommendations.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
- CSV Dataset
