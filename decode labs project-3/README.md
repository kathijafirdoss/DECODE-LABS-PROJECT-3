# DecodeLabs Project 3 - AI Recommendation Logic

## 📌 Project Overview

This project is part of the DecodeLabs Artificial Intelligence Industrial Training.

The objective is to create a simple recommendation system based on user preferences.

The system takes user interests as input, compares them with item attributes using similarity logic, and displays recommended items.

## 🤖 Recommendation Approach

The project uses:

- TF-IDF Vectorization
- Cosine Similarity
- User Preference Matching

The similarity score is used to rank items and provide the most relevant recommendations.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
- CSV Dataset
